# Scientific Claim Verification

## Overview

This project aims to build a system verifies scientific claims against retrieved evidence and abstains when the model is insufficient confident.

## Planned Pipeline

Claim
  ↓
Evidence Retrieval
  ↓
Evidence Selection
  ↓
SciBERT Classification
  ↓
Confidence Estimation
  ↓
Prediction / Abstention

## Tech Stack
- Python
- PyTorch
- Huggingface Transformers
- SciBERT
- scikit-learn


An evidence-based scientific claim verification system using SciBERT, information retrieval, and confidence-based abstention.
